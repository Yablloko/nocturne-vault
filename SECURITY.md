# Безопасность

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости в обычных Issues. Используйте приватный отчёт через раздел **Security → Report a vulnerability** в GitHub.

В отчёте укажите затронутую версию, условия воспроизведения, ожидаемое и фактическое поведение. Не прикладывайте настоящие пароли, ключи восстановления и содержимое личного хранилища.

Получение отчёта будет подтверждено в течение семи дней. Срок исправления зависит от риска и сложности изменения.

## Область поддержки

Исправления безопасности выпускаются для последней версии приложения Windows. Установщики следует брать только со страницы Releases этого репозитория и проверять по опубликованной контрольной сумме SHA-256.

Независимый внешний аудит криптографии проекта пока не проводился.
