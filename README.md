## Что это

Nocturne Vault объединяет привычный файловый порядок и защищённое хранилище. Папки открываются двойным щелчком, элементы выделяются одним щелчком и перетаскиваются мышью, а `Enter` и `Escape` работают так же, как ожидаешь от Проводника Windows.

| Раздел | Что внутри |
| --- | --- |
| **Пароли** | Учётные записи, генератор паролей, теги, избранное и безопасное копирование |
| **Коды доступа** | Локальные TOTP-коды, импорт QR и `otpauth://` |
| **Заметки** | Текст, прикреплённые изображения, папки и быстрый поиск |
| **Медиатека** | Фото, видео и аудио с просмотром внутри приложения |
| **Документы** | TXT, Markdown, PDF, Office, OpenDocument и история текстовых версий |
| **Быстрый доступ** | Защищённая панель с буфером, снимками, заметками, паролями и кодами |

## Главное

- **Без аккаунта.** Приложение готово к работе сразу после создания локального хранилища.
- **Без обязательного интернета.** Основные функции работают полностью офлайн.
- **Один порядок везде.** Вложенные папки, теги, избранное, перенос мышью и пакетное выделение доступны во всех разделах.
- **Светлая и тёмная темы.** Интерфейс поддерживает русский и английский языки.
- **Интеграция с Windows.** Контекстное меню Проводника, системный трей, скрытый автозапуск и захват области экрана.
- **Восстановление без сервера.** Зашифрованную резервную копию можно перенести и открыть мастер-паролем.

## Как защищаются данные

- основной контейнер и файлы шифруются с помощью AES-256-GCM;
- ключ из мастер-пароля получается через `scrypt` с уникальной солью;
- мастер-пароль не сохраняется и не отправляется разработчику;
- приложение блокируется при бездействии, сне и блокировке Windows;
- защита окна может запретить захват содержимого и скрыть его при потере фокуса;
- медиа и документы просматриваются без открытых временных копий;
- корзина остаётся зашифрованной до восстановления или окончательного удаления.

> [!IMPORTANT]
> Храните мастер-пароль и резервную копию отдельно. Без мастер-пароля, быстрого кода или recovery-ключа расшифровать данные невозможно.

Подробнее: [политика безопасности](SECURITY.md).

## Установка

Готовые версии для Windows публикуются в [Releases](https://github.com/Yablloko/nocturne-vault/releases). Для обновления достаточно запустить установщик новой версии поверх установленной — хранилище пользователя не удаляется.

### Сборка из исходников

Понадобятся Windows и Node.js 22 или новее.

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm start
```

Сборка NSIS-установщика:

```powershell
pnpm dist:win
```

Результат появится в `dist/Nocturne-Vault-Setup-0.8.13.exe`.

## Проверка проекта

```powershell
pnpm check
pnpm test
node tests/ui-smoke.js
node tests/quick-ui-smoke.js
node tests/quick-restart-ui-smoke.js
```

GitHub Actions запускает статическую проверку и функциональные тесты при каждом push и Pull Request. UI smoke-тесты дополнительно проверяют собранное приложение локально в Windows.

## Структура

```text
src/
├── main.js             Главное окно, системный трей и интеграция с Windows
├── renderer/           Интерфейс основного приложения
├── quick/              Панель быстрого доступа
└── services/           Шифрование, хранение, документы, TOTP и настройки
tests/                  Функциональные и интерфейсные проверки
build/                  Настройки Windows-установщика
assets/                 Иконка приложения
```
