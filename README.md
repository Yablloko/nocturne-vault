# Nocturne Vault

Локальное зашифрованное хранилище для Windows: пароли, одноразовые TOTP-коды, заметки, документы, фотографии, видео и защищённая панель быстрого доступа без аккаунта и облачного сервера.

[![Проверка](https://github.com/Yablloko/nocturne-vault/actions/workflows/ci.yml/badge.svg)](https://github.com/Yablloko/nocturne-vault/actions/workflows/ci.yml)

## Возможности

- мастер-пароль и одноразовый recovery-ключ;
- шифрование контейнера и медиа через AES-256-GCM;
- получение ключа из мастер-пароля через `scrypt`;
- PIN или графический ключ для текущего сеанса;
- автоматическая блокировка по бездействию, сворачиванию, сну и блокировке Windows;
- менеджер паролей с генератором и автоматической очисткой буфера обмена;
- вложенные папки, теги, избранное и пакетные операции во всех разделах;
- импорт файлов перетаскиванием и через контекстное меню Проводника;
- захват выбранной области экрана сразу в медиатеку;
- локальный TOTP-аутентификатор с импортом QR-кода, `otpauth://` и ручным вводом;
- зашифрованные заметки с прикреплёнными фотографиями;
- локальная медиатека без незашифрованных временных копий;
- внутренний редактор TXT/Markdown с зашифрованной историей версий;
- безопасный просмотр PDF, DOCX, XLSX, PPTX, RTF и OpenDocument внутри приложения;
- запись аудио с микрофона напрямую в зашифрованную медиатеку;
- зашифрованная корзина с восстановлением, сроком хранения и окончательным уничтожением;
- защита окон от захвата Windows и скрытие содержимого при потере фокуса;
- опциональный скрытый автозапуск вместе с Windows без автоматической разблокировки;
- работа в фоне через значок в системном трее;
- верхняя React-панель с историей последних 30 текстов и снимков экрана;
- доступ к названиям заметок и паролей из панели только после повторного ввода мастер-пароля;
- опциональное уничтожение ключа и локальных файлов после заданного числа ошибок.

## Запуск

Требуется Node.js 22+.

```powershell
pnpm install
pnpm start
```

Сборка установщика Windows:

```powershell
pnpm dist:win
```

Готовый NSIS-установщик появляется в `dist/Nocturne-Vault-Setup-0.8.13.exe`.

Проверки:

```powershell
pnpm check
pnpm test
```

## Формат данных

Данные приложения находятся в стандартной папке `userData` Electron. Основной AES-контейнер расположен в `vault-data`: метаданные, записи, заметки, настройки и имена папок входят в зашифрованный payload, а медиафайлы шифруются независимыми аутентифицированными блоками для безопасного потокового просмотра. История быстрого доступа хранится отдельно в `quick-data`, шифруется AES-256-GCM, а её случайный ключ защищается Windows DPAPI. При самоуничтожении удаляются оба ключа и очищаются оба локальных контейнера.

Удаление на современных SSD не может гарантировать физическое стирание каждой старой ячейки. Поэтому основная гарантия уничтожения обеспечивается удалением случайного ключа хранилища; перезапись файлов выполняется как дополнительная мера.

## Безопасность

Репозиторий проходит статические проверки и автоматические тесты. Независимый внешний аудит криптографии пока не проводился.
