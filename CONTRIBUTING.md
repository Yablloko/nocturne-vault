# Участие в разработке

[Русский](CONTRIBUTING.md) · [English](CONTRIBUTING.en.md)

Спасибо за интерес к Nocturne Vault. Изменения должны сохранять три свойства проекта: локальную работу, понятный интерфейс и безопасную обработку личных данных.

## Перед началом

- для новой возможности сначала создайте Issue и опишите пользовательскую задачу;
- исправление небольшой ошибки можно сразу прислать отдельным Pull Request;
- не объединяйте несвязанные изменения в одном Pull Request;
- не добавляйте сборки, пользовательские данные, ключи, пароли, локальные отчёты и сгенерированные файлы.

## Локальная проверка

Понадобятся Windows и Node.js 22 или новее.

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm check
pnpm test
node tests/ui-smoke.js
```

Изменения шифрования, разблокировки, импорта, экспорта или удаления данных должны сопровождаться тестами. Для заметного изменения интерфейса приложите скриншот светлой и тёмной темы.

## Pull Request

Опишите, что изменилось, зачем это нужно и как проверено. Убедитесь, что CI завершился успешно и в diff нет секретов или машинных путей.

Уязвимости не следует публиковать в Issues. Используйте порядок из [SECURITY.md](SECURITY.md).
