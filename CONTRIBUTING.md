# Участие в разработке

## Перед изменением

Для заметного изменения сначала создайте Issue с коротким описанием задачи. Исправления ошибок можно сразу присылать отдельным Pull Request.

## Локальная проверка

Понадобятся Windows и Node.js 22 или новее.

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm test
```

Один Pull Request должен решать одну задачу. Не добавляйте в репозиторий сборки, пользовательские данные, ключи, пароли, локальные отчёты и сгенерированные файлы.

Изменения, затрагивающие шифрование, разблокировку, импорт, экспорт или удаление данных, должны сопровождаться тестами.
