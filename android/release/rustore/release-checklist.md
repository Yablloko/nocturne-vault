# Чек-лист первого релиза Nocturne в RuStore

## Готово в проекте

- [x] Package name: `com.nocturne.vault`.
- [x] Версия увеличивается через `versionCode` и `versionName`.
- [x] Минимальная версия Android 8.0, target SDK 36.
- [x] Release APK подписан постоянным RSA-4096 сертификатом.
- [x] Подпись APK v2/v3 проходит проверку.
- [x] Release не является debuggable.
- [x] Включены R8 и shrinkResources.
- [x] Запрещён незашифрованный HTTP-трафик.
- [x] Отключены Android Backup и перенос внутренних данных.
- [x] В APK отсутствуют интернет, реклама, аналитика и `AD_ID`.
- [x] Подготовлены тексты карточки и декларация разрешений.
- [x] Подготовлены четыре актуальных скриншота 1080×1920 без персональных данных.
- [x] Все 33 инструментальных Android-теста прошли в личном профиле эмулятора API 36; три профильные проверки дополнительно успешно выполнены внутри рабочего профиля.

## Обязательно до отправки на модерацию

- [ ] Проверить уникальность `com.nocturne.vault` при создании приложения в RuStore Консоли. После первого релиза package name менять нельзя.
- [ ] Указать реальные ФИО/наименование, ИНН, адрес и email поддержки.
- [ ] Заменить заполнители в `privacy-policy-DRAFT-ru.md` и опубликовать политику по постоянной HTTPS-ссылке.
- [ ] Создать независимую зашифрованную резервную копию release-ключа и проверить её восстановление.
- [ ] Загрузить иконку `store-icon-512.png`.
- [x] Подготовить не менее трёх актуальных скриншотов телефона без тестовых секретов и персональных данных.
- [ ] Заполнить декларацию данных и обосновать `RECORD_AUDIO`.
- [ ] Указать контакт разработчика и инструкцию модератору.

## Ручное тестирование релизного APK

- [ ] Чистая установка: онбординг, создание хранилища, блокировка и повторный вход.
- [ ] Обновление поверх предыдущей версии без потери данных.
- [ ] Неверный мастер-пароль, PIN и рисунок; восстановление через мастер-пароль.
- [ ] Экспорт резервной копии, сброс тестового хранилища и импорт копии.
- [ ] Пароли: создание, изменение, удаление, папки, корзина.
- [ ] Автозаполнение отдельно для логина, пароля и пары полей в браузере и приложении.
- [ ] TOTP: ручной ключ, QR с камеры и QR из изображения.
- [ ] Файлы: пакетный импорт, просмотр фото/видео/PDF/текста, удаление и восстановление.
- [ ] Аудиозаметка с разрешением микрофона и после отказа в разрешении.
- [ ] Автоблокировка при бездействии, сворачивании и открытом диалоге настроек.
- [ ] Очистка буфера на выбранных интервалах.
- [ ] Режим без сети: все локальные функции работают.
- [ ] Проверка на маленьком экране и при открытой клавиатуре.

## Команды перед загрузкой

```powershell
cd android
.\build-release.ps1
```

Однократно создайте резервную копию ключа на внешнем защищённом носителе:

```powershell
.\export-signing-backup.ps1 -OutputPath 'E:\Nocturne-release-key-backup.p12'
```
