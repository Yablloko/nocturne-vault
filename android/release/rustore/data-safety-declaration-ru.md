# Декларация данных и разрешений для RuStore

Документ подготовлен по фактическому манифесту Nocturne 0.9.11. Перед отправкой следует сверить его с результатом автоматической проверки загруженного APK в RuStore Консоли.

## Чувствительные разрешения

### `android.permission.RECORD_AUDIO`

- Цель: запись аудиозаметки после нажатия пользователем кнопки записи.
- Когда запрашивается: непосредственно перед первой записью.
- Обработка: запись шифруется и хранится только во внутреннем хранилище приложения.
- Передача: аудиозаписи не передаются разработчику или другим третьим лицам.
- Поведение при отказе: все функции, кроме записи аудиозаметок, продолжают работать.

### `android.permission.USE_BIOMETRIC` / `android.permission.USE_FINGERPRINT`

- Цель: добровольная быстрая разблокировка через защищённое системное окно Android.
- Биометрические шаблоны не доступны приложению и не сохраняются в Nocturne.
- При отказе остаётся вход по мастер-паролю, PIN или рисунку.

## Сетевые разрешения

В release-сборке отсутствуют `android.permission.INTERNET` и `android.permission.ACCESS_NETWORK_STATE`. Приложение не содержит рекламного или аналитического SDK и не может самостоятельно отправлять данные в сеть.

## Прочие разрешения и системные службы

- `android.permission.WAKE_LOCK`: добавляется медиакомпонентом и используется во время воспроизведения медиа.
- `android.permission.RECEIVE_BOOT_COMPLETED`: закрывает сессию защищённого рабочего профиля после загрузки или перезагрузки устройства.
- `android.permission.REQUEST_PASSWORD_COMPLEXITY`: позволяет на Android 11 проверить, что для рабочего профиля действительно установлен отдельный системный код; само приложение код не читает и не сохраняет.
- `android.permission.SCHEDULE_EXACT_ALARM`: гарантирует закрытие временной сессии защищённых приложений не позднее установленного срока.
- `android.permission.QUERY_ALL_PACKAGES`: используется только контроллером рабочего профиля, чтобы приостанавливать все установленные в нём гостевые приложения, включая приложения без значка запуска.
- `android.permission.BIND_AUTOFILL_SERVICE`: системное разрешение защищает службу автозаполнения; пользователь включает Nocturne вручную в настройках Android.
- `android.permission.BIND_CREDENTIAL_PROVIDER_SERVICE`: системное разрешение защищает Credential Provider на поддерживаемых версиях Android.

## Категории пользовательских данных

### Данные хранилища

Пароли, логины, URL, заметки, TOTP-секреты, фото, видео, аудио и документы:

- обрабатываются локально;
- не собираются разработчиком;
- не передаются третьим лицам;
- шифруются во внутреннем хранилище;
- экспортируются только по явному действию пользователя в зашифрованную резервную копию.

### Сторонний сбор данных

Рекламные и аналитические SDK отсутствуют. Nocturne не собирает телеметрию и не передаёт содержимое хранилища разработчику.

## Защитные настройки APK

- `android:allowBackup="false"`;
- облачное резервное копирование и перенос данных Android исключены;
- `android:usesCleartextTraffic="false"`;
- release-сборка не отлаживаемая;
- включены R8-обфускация и удаление неиспользуемых ресурсов;
- экспортированные службы защищены системными signature-разрешениями Android.
